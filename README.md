# Prospekt — website

The marketing site for [Prospekt](https://github.com/UrsaCode/prospekt),
published with GitHub Pages from this `gh-pages` branch.

The extension's own code lives on `main`; this branch holds only the site, so
the two never tangle. Served at `https://ursacode.github.io/prospekt/`, and
mirrored at `https://ursacode.com/prospekt/` — the canonical tags point at the
`ursacode.com` copy, which stays the primary home.

Pulled from cPanel, where the live site is stored. Absolute `/prospekt/` links
resolve correctly here because the Pages base path is also `/prospekt/`.
